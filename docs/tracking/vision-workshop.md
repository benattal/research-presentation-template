## 2026-11-17 — Moved into the template layout

The four workshops moved from the `stem-hs-diffusion` repository (history
there, last commit `381783a`) into `presentations/<id>/` of this template:
`diffusion`, `filtering`, `tracking` (was `face-and-hand-tracking`),
`image-manipulation` (was `image-minipulation`, served at `/image-manip/`).
The server-rendered landing page became the `home` presentation. Slide media
and source decks moved to the bucket (DATA.md).

Behavior changes a presenter will notice:

- `PRESENTER_PASSWORD` must be set in `.env` or the hosting environment; the
  password is no longer in the source.
- `VITE_VOTING_DISABLED` and `VITE_PRESENTER_CONTROLLED` are gone; the server
  variables `VOTING_DISABLED` and `PRESENTER_CONTROLLED` alone control both
  features.
- Votes are recorded per browser on the server. Changing a vote replaces it;
  the presenter's "vote many times to test" behavior is gone.
- Notes edits are saved to the notes files under the development server only;
  production presenter windows show notes read-only.
- The image-manipulation workshop is at `/image-manipulation/`.
- Slides look the same on every screen size: the per-layout phone layouts
  (viewport media queries) were removed, because the stage is scaled rather
  than reflowed.

Layout bugs fixed (from a read-only audit of every layout):

- diffusion: noise slider showed a stale or clean image after switching
  images (load race, fixed 100 ms timer); diffusion sequence could show the
  wrong image after quick hovers; noise-definition demo threw if left before
  its image loaded; the title background's tile count grew with the window
  size; `sequenceImage` was ignored; the CLIP plot started with no point
  highlighted.
- filtering: the kernel editor could not accept negative numbers or empty
  cells; the convolution animation's Reset at the first position left the
  first output cell empty, and playback continued while hidden; frame
  extraction for the temporal blur demo hung on a failed video and kept
  running after leaving the slide; kernel and image polls inherited the vote
  drift fixed in the framework.
- tracking: the numeric poll's `autoFocus` blocked the presenter's keys;
  its reset went to the wrong endpoint; the numeric poll route was missing
  from the development server; resubmissions were unlimited.
- image-manipulation: the panorama's completion banner could appear after a
  reset; dragging the retouching divider or panorama thumbnails on a touch
  screen changed slides.
- poll results truncated long option labels with an ellipsis; they now wrap.

The filtering notebook's saved outputs and widget state (6 MB, regenerated by
running it) were stripped from the git copy; the notebook with outputs is in
the `stem-hs-diffusion` history.
