The second tutorial. The first one (`npm run tutorial`) has you edit a deck's files by hand; take it first, because this one assumes you know what a slide's file looks like.

Here you do not edit anything. Each task gives you words to say to a coding agent that is working in this repository. The agent changes this deck, the page reloads, and the slide reads the deck to see whether the task was done.

You need a coding agent that can read and edit files and run commands here: Claude Code, or any other that reads `AGENTS.md`.
