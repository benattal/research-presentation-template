# data

Generated data about the presentations, kept out of git.

- `captures/<id>/<YYYYmmdd-HHMMSS>/`: visual validation runs from
  `npm run capture -- <id>` (screenshots, `report.json`, and the
  `index.html` contact sheet). See
  [visual validation](../docs/implementation/visual-validation.md).

Media the presentations show are not here: they live in each presentation's
`public/` and `assets/` and in the bucket ([DATA.md](../DATA.md)).
